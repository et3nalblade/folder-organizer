# Folder Organizer

Сортирует файлы из одной папки по типам: изображения, документы, таблицы, аудио, видео, архивы, код и прочее.

## Особенности

- сначала показывает план и ничего не перемещает;
- перемещение запускается только с флагом `--apply`;
- не обрабатывает вложенные папки и символические ссылки;
- при совпадении имён добавляет суффикс, не затирая файл;
- использует только стандартную библиотеку Python.

Требуется Python 3.10 или новее.

## Использование

Предпросмотр:

```bash
python organize.py "C:/Users/you/Downloads"
```

Выполнить перемещения:

```bash
python organize.py "C:/Users/you/Downloads" --apply
```

Сначала попробуйте программу на тестовой папке с копиями файлов. Запускайте её только для папок, содержимое которых вы хотите изменить.
